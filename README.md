# 🚗 Car Price Prediction Using Machine Learning

### CodeAlpha Data Science Internship – Task 2

## 📌 Project Overview

What determines the price of a used car? Is it the brand, manufacturing year, mileage, or other vehicle features?

This project focuses on predicting the selling price of used cars using Machine Learning techniques.

Using Python and the **Random Forest Regressor** algorithm, this project analyzes different car-related features and estimates the expected selling price.

The goal is to build a predictive model that helps understand how different factors influence the market value of used cars.

## 🎯 Project Objectives

- Analyze a used-car dataset.
- Perform data cleaning and preprocessing.
- Explore relationships between car features and selling prices.
- Visualize important patterns and trends in the dataset.
- Train a Random Forest Regression model.
- Predict used-car selling prices using the trained model.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## 🤖 Machine Learning Algorithm

**Random Forest Regressor**

Random Forest is an ensemble learning algorithm that combines multiple decision trees to make predictions. It is used in this project to estimate the selling price of used cars based on their features.

## 📊 Project Workflow

1. Dataset collection and loading.
2. Data exploration and understanding.
3. Data cleaning and preprocessing.
4. Exploratory Data Analysis (EDA).
5. Model building and training.
6. Price prediction and model evaluation.
